# Day 3: Polygons
Otautahi Christchurch: 184,921 land parcels, each given a random colour.

- Tool: ArcGIS Pro
- Data: Land Information New Zealand (LINZ) NZ Parcels, CC BY 4.0
- Method: definition query (topology_type = Primary, minus road, hydro, riverbed and railway parcel intents), then a random colour field (0 to 7) with an 8-colour palette; Hagley Park recoloured by hand; soft shadow layers under the city edge
- Palette: inspired by pounamu, kowhai and Canterbury earth tones
- Inspiration: Andrew Douglas-Clifford's Hamilton parcel map
