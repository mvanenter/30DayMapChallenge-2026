# Day 2: Lines
Which way do the streets point? Every street in Christchurch, coloured by compass direction.

- Tool: ArcGIS Pro
- Data: OpenStreetMap contributors (ODbL) via Geofabrik, roads layer clipped to Christchurch City; boundary from Stats NZ
- Method: Calculate Geometry Attributes (line bearing), then Calculate Field to group bearings into four direction classes (north-south, east-west, NE-SW, NW-SE)
- Style: bright colours on a dark background, with a soft glow layer underneath
